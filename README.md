# Onboarding Form Application

A robust, responsive onboarding form application built with React, TypeScript, and Ant Design. This project demonstrates modern frontend practices including custom hooks, form validation, unit testing, and strict linting.

## Features

- **Form Management**: Built using Ant Design Form components.
- **Validation**:
  - Required field validation.
  - Phone number formatting and validation.
  - Asynchronous Corporation Number validation.
- **State Management**: Custom `useOnboardingForm` hook for handling form logic and loading states.
- **Styling**: Custom styling using SCSS with nested rules and variables.
- **Testing**: Comprehensive integration tests using React Testing Library and Jest.
- **Code Quality**: Configured with ESLint and Prettier for consistent code style.

## Tech Stack

- **Framework**: React (v18)
- **Language**: TypeScript
- **UI Library**: Ant Design
- **Styling**: Sass (SCSS)
- **Testing**: Jest, React Testing Library
- **Linting/Formatting**: ESLint, Prettier
